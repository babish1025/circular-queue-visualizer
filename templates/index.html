💡 Circular Queue Fundamentals

A Circular Queue is an advanced linear data structure that overcomes the memory-wasting limitation of a standard linear array queue. In a regular linear queue, once the rear pointer reaches the end of the array, no new elements can be enqueued even if slots at the beginning have been vacated by dequeue operations.

↻ Circular Modulo Arithmetic
Next REAR = (REAR + 1) % Capacity Next FRONT = (FRONT + 1) % Capacity

Key Mathematical Conditions

  • Initial State: FRONT = -1, REAR = -1, SIZE = 0
  • Empty Check (Underflow): SIZE == 0 (or FRONT == -1)
  • Full Check (Overflow): SIZE == Capacity or (REAR + 1) % Capacity == FRONT
  • Single Element Dequeue: When the last remaining element is dequeued, reset FRONT = -1, REAR = -1.

Physical Array vs. Logical FIFO Order

In memory, array indices are fixed from 0 to Capacity - 1. However, because of the circular wrap-around, the logical front of the queue may sit at a higher index than the logical rear!

Physical Indices: [0]   [1]   [2]   [3]   [4]
Array Contents: [60]   [70]   [30]   [40]   [50]
Pointers:         ↑ REAR=1      ↑ FRONT=2
Logical Queue: 30 → 40 → 50 → 60 → 70
